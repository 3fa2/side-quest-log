# 支线任务清单 · Side Quest Log

你的生活很无聊，因为它没有支线任务。你起床、工作、刷屏、睡觉。重复。没有风险，没有故事，没什么可跟别人说的。

这里准备了 34 个支线任务，3 个月内完成。**按模块选你想做的，真正去做。**

> 在线体验：https://3fa2.github.io/side-quest-log/

## 这是什么

一个纯前端、零依赖的生活任务管理工具。把「人生支线任务」拆成健康、心灵、金钱、人际、冒险 5 大模块，按自己的节奏接任务、打卡、完成，用游戏化的方式坚持下来。

任务 34 是唯一重要的，其余 33 个只是通往它的途径。

## 功能

- **5 大模块 34 个任务**：健康 / 心灵 / 金钱 / 人际 / 冒险，每个任务带难度星级、建议周期和具体做法
- **任务大厅**：按模块自选任务，随时换任务、放弃重选
- **XP 经验系统**：按难度获得 100/200/300 XP，打卡 +10 XP
- **等级成长**：10 个等级，从见习冒险者到神话存在
- **15 个成就徽章**：含隐藏成就「十年之约」（完成任务 #34）
- **13 周远征时间线**：当前周金色高亮
- **模块进度环 + 连续打卡火苗 + 完成撒花特效**
- **自定义任务**：自己添加标题、做法、分类和难度
- **设置面板**：截止日期、同时可接上限、导出/导入/备份

## 使用方法

1. 打开 `index.html`（或直接访问在线链接）
2. 在任务大厅按模块挑选任务（建议同时只接 5 个）
3. 每天打卡，完成后获得 XP 和徽章
4. 数据保存在浏览器 localStorage，**不联网、不上传**，隐私安全

## 技术栈

纯 HTML + CSS + JavaScript 单文件实现，无任何依赖，双击即可运行。
